# v1.0.0 · G2rain（谷雨）知识对话主应用

本版本准备 G2rain（谷雨）开源智能体平台的知识对话主应用源码与 GHCR 镜像发布流程。主应用承载对话入口、导航、会话协调和微前端运行能力；具体平台能力与开放状态以 [G2rain 主仓库](https://github.com/g2rain/g2rain) 为准。

## 首版包含的能力

- 对话界面提供会话列表、消息展示、输入区、执行过程时间线及追踪信息展示；具体回答与数据由后端服务提供。
- Shell 提供 Header、Sidebar、Tab 和 Workspace，负责导航、菜单、地址栏同步及子应用生命周期编排；业务微应用入口须来自可信目录。
- 集成 `@g2rain/platform/main`、`@g2rain/http`、主题和 UI 包，协调 SSO 会话、Token 刷新与跨应用定向消息。最终鉴权仍由 Gateway 和业务服务负责。
- 使用 `/chat` Context Path；OpenResty 托管静态资源，内置 Lua Application-DPoP 签名脚本、Nginx 模板及启动入口，运行时密钥需挂载注入。

## 构建与镜像

要求 Node.js 22 或以上及 npm。`npm ci` 安装锁定依赖，`npm run build` 执行 TypeScript 类型检查与 Vite 生产构建。本仓没有独立的 `npm test` 脚本。容器复用根目录 `Dockerfile` 和 `build.sh`，运行时为 OpenResty，监听容器端口 `8080`，入口为 `/docker-entrypoint.sh`。

- npm 项目版本为 `1.0.0`。
- 复用现有 Dockerfile 构建 OpenResty 运行镜像，加入 OCI 源仓库、版本、提交和许可证元数据。
- 稳定版标签 `v1.0.0` 触发 GitHub Actions 构建，预期镜像标签为 `ghcr.io/g2rain/g2rain-chat-shell:1.0.0` 和 `sha-<完整提交 SHA>`。
- Docker 构建上下文包含已跟踪的 `.env.production` 构建配置，排除其他 `.env*` 本地配置和 `lua/keys/` 运行时密钥目录；签名脚本进入镜像，密钥不进入镜像层。

仓库目前仍跟踪 `lua/keys/` 下的密钥命名文件。维护者在公开源码前须确认它们是否仅为可公开样例，并处理任何非公开凭据；Docker 排除规则不会改变 Git 中已有文件的可见性。

## 发布顺序

按本仓 `feature/* → develop → main` 流程，先将版本、工作流和本说明合入 `main`，再在已验证的 main 提交创建并推送 `v1.0.0`。工作流检查标签格式、提交所属分支历史及同名发布说明，使用 GitHub 提供的 `GITHUB_TOKEN` 推送镜像。首次推送后，如需匿名拉取，应在 GitHub Packages 将包设为 Public；后续版本沿用同一包的可见性设置。操作详见[部署文档](../operations/deployment.md)。

## 验证状态与已知限制

本模块已在 [demo.g2rain.com/chat/](https://demo.g2rain.com/chat/) 获得在线演示环境验证（维护者反馈）；该记录对应演示站点的浏览器端使用，不代表本次待发布 GHCR 镜像已完成构建、推送或部署验收。发布准备阶段另已在本地执行 `npm ci` 和 `npm run build`，类型检查与 Vite 构建通过。Docker 引擎当时不可用，容器构建、GHCR 推送及匿名拉取仍待验证；实际结果以 Actions 运行记录和目标环境验收为准。工作流不自动创建 GitHub Release、部署服务或更新 `latest`。

生产微路径刷新回退、真实 IAM/Gateway/Sign 联调及运行时密钥注入的完整验收范围尚未由本次发布准备检查确认。Token 本地持久化、同页 Auth Bridge 等已知风险和退出条件见[已知偏差](../architecture/deviations.md)。本仓使用 [Apache License 2.0](../../LICENSE)，项目包元数据和镜像许可证标签均为 `Apache-2.0`。
