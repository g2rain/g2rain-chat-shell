# v1.0.0 · G2rain（谷雨）知识对话主应用

本版本准备 G2rain（谷雨）开源智能体平台的知识对话主应用源码与 GHCR 镜像发布流程。主应用承载对话入口、导航、会话协调和微前端运行能力；具体平台能力与开放状态以 [G2rain 主仓库](https://github.com/g2rain/g2rain) 为准。

## 本次变更

- npm 项目版本为 `1.0.0`。
- 复用现有 Dockerfile 构建 OpenResty 运行镜像，加入 OCI 源仓库、版本、提交和许可证元数据。
- 稳定版标签 `v1.0.0` 触发 GitHub Actions 构建，预期镜像标签为 `ghcr.io/g2rain/g2rain-chat-shell:1.0.0` 和 `sha-<完整提交 SHA>`。
- Docker 构建上下文排除 `.env*` 本地配置和 `lua/keys/` 运行时密钥目录。

## 发布与验证状态

发布改动和本说明须先进入 `main`，再在该提交创建并推送 `v1.0.0`。工作流不自动创建 GitHub Release、部署服务或更新 `latest`。本说明不宣称尚未执行的 CI 镜像构建、推送或部署验证；实际结果以 Actions 运行记录为准。
